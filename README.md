 🎬 Movie Genre Classification using NLP

An NLP-based machine learning model that predicts movie genres based on plot summaries and descriptions using TF-IDF vectorization and Naive Bayes classification.

## 🛠️ Tech Stack & Workflow
- **Language:** Python 3
- **Libraries:** Pandas, NLTK, Scikit-Learn
- **Text Processing:** Lowercasing, Stop-word removal, Special character removal
- **Feature Extraction:** TF-IDF (Term Frequency-Inverse Document Frequency)
- **Classification Model:** Multinomial Naive Bayes

## 📊 Results & Key Features
- Successfully classifies movie plots into multi-class genres (Action, Drama, Comedy, etc.).
- Includes custom prediction functions for real-time plot testing.
